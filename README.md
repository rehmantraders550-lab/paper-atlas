# The Paper Atlas

A Pakistan-first paper and board reference library.

## Launch scope
Searchable catalogue, material details, Light Table and two-material Comparison Desk. Restrained glass panels on navigation and controls; clear surfaces for facts and imagery.

Five public fields: name, material family, common uses, surface/feel and manufacturing origin. Unknown origins remain unknown. Generated images are labelled illustrative renderings, not measured samples.

## Status
Foundation and publication validation are in progress. No website is deployed. Material evidence must be reviewed before publication.

## Development
Run foundation checks with `python -m unittest discover -s foundation -p 'test_*.py'`.

Private research, chat exports, credentials and unreviewed records do not belong in this public repository.
